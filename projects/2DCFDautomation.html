2D CFD Automation

Journal scripting of Automated Simulation for a 2D CFD (NACA0012) in ANSYS Fluent

Background & Overview

Running a CFD study by hand means repeating the same sequence: case setup, execution, post-processing; for every angle of attack under investigation. It's necessary work, but not work that benefits from being done manually, over and over, run after run. This project began as an effort to remove that repetition.

This is an automated workflow, where one can load a single file into ANSYS Fluent, and everything downstream (setup, simulation, and post-processing) for a single-run CFD study of 2D airfoils (or other 2D geometries) is handled automatically. Rather than locking users into a fixed physics setup, the scripts deliberately leave the governing equation selection open; giving the workflow flexibility to extend across different solver configurations as the project evolves. The journal scripting (.jou), native to the ANSYS Fluent platform is used for this project. I have attached a pdf file in the repo that contains more information on how to use the scripts.

Please consult my Git repository page (linked below) for more technical in-depth. Alongside the core scripts, the repository also includes the aforementioned pdf file and supplementary Python scripts to support independent studies using the same workflow.

Features

Multiple Journal File: There are a couple of .jou file. One for first run, the other for subsequent runs for a single project. Supplimentary Python Script: In order to manipulate AoA between runs, a supplementary Python script has also been added, where the user can extract key values and plug them into the journal for multiple simulation runs with different AoA values. Python Script for Re Conversion: Developed for a different project, this Python script can take input of critical variables and convert Re numbers to fluid velocity, and vice versa. A simple calculator script that the user could find useful. Portable Document Format File: A pdf file has also been added as a tutorial for first time users. However, readers are expected to possess prior working knowledge of ANSYS Fluent, as this documentation assumes familiarity with essential computational fluid dynamics concepts and does not address foundational simulation techniques.

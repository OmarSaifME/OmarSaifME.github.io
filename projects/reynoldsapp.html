Reynold's App

A software that includes helpful fluid mechanical calculations for CFD and beyond, developed with Python.

Background & Overview

Computational Fluid Dynamics require a lot of pre-processing (and validation) calculation, that are not always directly embedded in the software of your choosing. For example, if you want to calculate the vector components of an 'angled flow' for your simulation, you need to do some trigonometric calculation that is usually beyond the scope of the CFD tool. And pulling a calculator, pencil, and paper every time you need to correct/update a settings value could hinder your progress. To address such issues, I have built a standalone desktop tool that covers some calculations on your behalf. Three modules have been developed for the current version of the app. More will be added based on needs. The app (and the source code) can be found on the git repository linked below. It is an open-sourced project with MIT licensing, designed to help students and academics in their CFD studies. Of course, to the critical eye; this could be considered as a glorified Excel workbook, but I digress!

Module 1: Angle of Attack

This module asks the user for the angle of attack, and flow velocity as inputs. Given the data, it calculates velocity components (vector) for X and Y axis, alongside values for drag and lift force vector - critical for coefficient report definitions.

Module 2: Reynolds Number Conversion

This module asks the user for the flow velocity, alongside some other critical values (characteristic length, fluid density, viscosity) to calculate the Re value. Based on the mode, it can also do the vice-versa.

Module 3: Grid Convergence Index

One of the most critical components for any CFD study is the grid independence validation. Grid Convergence Index (based on Roache, 1994) is a mathematical tool to quantify the uncertainty of a given mesh for a computational study. This module takes the refinement ratio, factor of safety, and values of key variables (coefficients for example) assuming a 3-grid setup (coarse, medium, fine); and then computes GCI for fine mesh, GCI estimates, and declares the state of asymptotic range for the given mesh.
